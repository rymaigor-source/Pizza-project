# Шаблон сайта пиццерии

Готовый сайт для пиццерии или кафе. Все тексты, цены, фото и часы работы лежат в папке `content/`
и меняются через админку по адресу `/admin`, код трогать не нужно.

## Что внутри

- `index.html`, `style.css`, `script.js` - сам сайт
- `content/settings.json` - название, телефон, адрес, часы, цвет, соцсети
- `content/menu.json` - разделы меню и блюда
- `admin/` - админка Decap CMS (формы для владельца)
- `images/uploads/` - сюда попадают загруженные фото

## Как опубликовать с iPhone

1. Создай аккаунт на github.com и новый репозиторий (Add file - Upload files, загрузи все файлы папки).
2. Открой `admin/config.yml` в репозитории и замени `YOUR_GITHUB_USER/YOUR_REPO` на свой репозиторий.
3. Зайди на pages.cloudflare.com (или netlify.com), выбери "Connect to Git" и свой репозиторий.
   Настройки сборки: команда сборки пустая, папка публикации `/` (корень).
4. Через минуту сайт откроется на адресе вида `название.pages.dev`.
5. Настрой вход в админку (см. ниже).

## Вход в админку

Шаблон настроен на Netlify Identity + Git Gateway: владелец заходит по e-mail и паролю,
аккаунт GitHub ему не нужен.

1. Опубликуй сайт на Netlify **из репозитория GitHub** (не через Netlify Drop, иначе админка не сможет сохранять).
2. В Netlify: Project configuration, Identity, Enable Identity.
3. Там же: Services, Git Gateway, Enable Git Gateway.
4. Identity, Invite users: пригласи e-mail владельца. Он получит письмо, зададит пароль и войдёт в `/admin`.

Способы входа у Decap менялись, поэтому сверься с актуальной инструкцией на decapcms.org/docs/git-gateway-backend.
Если на Cloudflare Pages: нужен вход через GitHub-бэкенд и отдельная служба OAuth (запасной вариант в `config.yml`).

## Как изменить сайт

Открой `ваш-сайт/admin`, войди и правь формы: "Основные настройки" и "Меню". Нажми "Опубликовать",
и через минуту изменения появятся на сайте.

## Свой домен

Купи домен у любого регистратора и подключи его в настройках Cloudflare Pages или Netlify
(раздел Custom domains), сервис сам выпустит HTTPS-сертификат.
